> 项目：chordDeck（FastAPI + Vue3/Vite 和弦识别 Web 应用）
> 文档版本：v1.0 · 2026-09-02

> **DAW（Cubase 类）编曲视图**并支持水平缩放。§4.2 的「迷你音轨+列表」设计作废，

> ③ 节拍网格**只显示在编辑工作台**的迷你音轨上（主播放器时间轴保持干净）；

## 1. 目标

1. **编辑工作台**：结果页「编辑」按钮弹出悬浮面板，用户可人工修正和弦序列——
   - 修改和弦名（文本输入，实时校验 + 键盘构成音预览）；
   - 移动和弦边界位置（迷你时间轴拖动 / ±0.1s / 直输时间）；
   - 插入 / 删除和弦标记；
   - 保存写回服务端，历史与结果页呈现修正版并标注「已编辑」。
2. **节拍识别与网格**：
   - 后端自动识别 BPM 与逐拍时刻（madmom-infer，librosa 兜底）；
   - 编辑工作台迷你音轨上绘制**小节线**（默认每 4 拍一条 + 小节编号）与可调密度的细分线
     （档位：小节 / 每拍 / 8 分音符 / 16 分音符）；
   - 拖动和弦边界时**吸附到网格**（可关），方便对准节拍；
   - 结果页展示 BPM。

风格约束：与现有「高端克制」主题一致（近黑暖底、金点、细线、衬线标题），
不使用冲突配色；交互与现有两段式删除、分段按钮、滑块保持一致。

## 2. 总体架构与数据流

```
上传/识别(analyze) ──► 和弦提取 + 节拍识别(惰性可容错) ──► SQLite
        │                                                    │ bpm/beats/edited
        ▼                                                    ▼
结果页(播放器) ◄── GET /api/analyses/{id} ── 含 bpm / edited
   │
   ├─「编辑」按钮 ──► EditWorkspace(悬浮) ──► GET /api/analyses/{id}/beats（取网格数据）
   │                       │                      （未缓存则此刻计算入库）
   │                       ▼
   │              列表编辑/拖动/增删 ──► PUT /api/analyses/{id}/chords
   │                       │               （重推简化档 + edited=1）
   │                       ▼
   └─ 保存后刷新 result + history（含「已编辑」徽标；BPM 徽标随结果展示）
```

关键点：
- 和弦编辑对象 = 记录的**完整档 `chords`**（规范数据）；保存时后端用现有
  `postprocess` 重新推导 `chords_simple`，保证双档 / 键盘 / 试听 / 导出一致。
- 节拍与和弦共用同一条音频时间轴，天然对齐；节拍数据与和弦引擎无关。
- 「重新识别」（含换引擎）会**覆盖人工编辑**：前端先弹确认；后端执行后重置 `edited`。

## 3. 后端设计

### 3.1 DB 迁移（db.py）

`analyses` 表新增 4 列（`ALTER TABLE ADD COLUMN`，幂等检测）：

```sql
bpm       REAL   DEFAULT NULL   -- 检测到的 BPM（未检测为 NULL）
beats     TEXT   DEFAULT NULL   -- JSON: [逐拍时刻, ...]
edited    INTEGER DEFAULT 0     -- 是否人工编辑过
edited_at TEXT   DEFAULT NULL
```

新增 helpers：`update_beats(rid, bpm, beats)`、
`mark_edited(rid, chords, chords_simple)`（写两档 + edited=1 + edited_at=now）、
`clear_edited(rid)`（重新识别后调用，保留新两档并置 edited=0）。
`chords_of()`、`find_by_*` 返回行已含新列，无需改动调用面。

### 3.3 接口（main.py）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/analyses/{id}/beats` | 惰性计算并缓存；返回 `{bpm, beats, source, cached}`；旧记录首次调用时计算 |
| `PUT` | `/api/analyses/{id}/chords` | body `{chords:[{timestamp,chord}]}`；服务端防御性排序/夹取/校验；写全档+重推简化档+`edited=1`；返回最新分析响应 |

- `analyze()`：和弦识别成功后**附带**执行 `extract_beats`（单独 try/except，
  失败仅记日志），随记录入库；响应新增 `bpm`、`beats_count`（不含全量 beats，减小 payload）。
- `_analysis_response()` / `_history_item()`：新增 `bpm`、`edited`、`edited_at`。
- `reanalyze()`：成功后 `clear_edited()`（人工修正被机器结果覆盖，前端已确认）。
- 响应中 `edited` 供前端徽标与确认流程使用。

## 4. 前端设计

### 4.1 通用小件

- `lib/events.js`：极简事件总线（`on/emit/off`），用于「打开编辑器时暂停播放」——
  `EditWorkspace` 打开时 `emit('player:pause')`，`ChordTimeline` 监听后 `pause()`。
- `components/ConfirmDialog.vue`：可复用确认框（标题/正文/确认/取消，暗色金点），
  用于「重新识别将覆盖人工修改」确认（历史行按钮与引擎切换共用）。

### 4.2 EditWorkspace.vue（核心）

**props**：`analysis`（含 id/filename/duration/chords/bpm）、`open`。
**emits**：`close`、`saved`(更新后的 analysis)。

**状态**：
```
chordsLocal   = 深拷贝 analysis.chords（编辑对象，完整档）
originJSON    = JSON.stringify(chordsLocal)      // 取消还原用
beats/bpm     = ref(null)  // 挂载后 GET beats（loading 态：细进度条）
density       = 'bar' | 'beat' | 'eighth' | 'sixteenth'   // 细分线档位（默认 beat）
beatsPerBar   = 4        // 每小节拍数 1–12（默认 4/4）
snapOn        = true     // 拖动吸附网格
invalidRows   = Set<index>  // 校验失败行 → 禁用保存
dirty         = computed(JSON 与 originJSON 不等)
```

**布局**（悬浮居中面板，遮罩 rgba(8,9,11,.66)+backdrop blur）：
```
标题栏：编辑和弦 · {filename}          [BPM ♩=128 · 网格每小节 N 拍] [取消][保存]
① 迷你音轨（网格 + 和弦标点，可拖动）
② 工具栏：密度 [小节|拍|8分|16分] · 每小节拍数 [1..12] · 吸附网格 [开关]
③ 和弦列表（每行）：
   [序号·起始时间 mm:ss.s] [和弦输入框+校验√/×] [键盘预览] [− 时间 +] [插入] [删除]
```

**① 迷你音轨**（复用时间轴视觉，独立实现，宽=容器）：
- **网格层**：小节线（`beats[i*beatsPerBar]`）金色；细分线按密度插值
  （相邻拍 `b[k]→b[k+1]` 间等分 n 条，n=1(拍)/2(8分)/4(16分)）淡灰；线仅按 `beats` 覆盖区间绘制。
- 小节线顶部标注序号（1,2,3…）。
- **和弦层**：标记竖线 + 标签（复用简化/完整显示规则，直接用完整档名）；
  拖动：pointerdown 选中该标记 → pointermove 水平拖动 → 候选时间
  = 夹取 `[prev.start, next.start]` → snapOn 时吸附到当前密度最近的线/拍 → 松手落定。
- 播放头：不显示（打开编辑器即暂停播放，专注编辑）。

**② 网格数据**（computed）：
```
lines = []  // {t, kind: 'bar'|'sub'}
bars = beats 中每 beatsPerBar 拍取一条
subs = density!=bar 时在相邻拍之间插值（小节线视为 bar 优先）
snapTarget(t) = 最近一条 lines.t（density=bar 时只吸附小节线）
```

**③ 列表行**：
- 和弦输入：`<input>`，`blur`/`input` 校验 `parseChordLabel`（空串/N 合法为 N；
  解析失败标红 + 提示，行进入 invalidRows）；
  合法时右侧**迷你键盘预览**（复用 `PianoKeyboard`，1–2 秒内点亮）。
- 时间调整：`− / +`（0.1s，夹取区间内）；双击时间可直输 `mm:ss.s`（解析失败恢复旧值）。
- 插入：在行首「＋」→ 在 `prev/当前` 之间插入新边界（时间=前段中点，和弦名=前段名，
  若为首条则 0s）。自动重排。
- 删除：行尾「删除」（两段式，与历史删除一致）；列表至少保留 1 条，删除后前段自然延长。

**保存**：`PUT /api/analyses/{id}/chords`；成功 → emit('saved', resp) 并关闭；
失败 → 面板内错误提示（不关闭）。
**取消/关闭**：直接丢弃（内存副本即可，未保存不写库）。

### 4.3 App.vue

- 结果页操作行（rf-actions）加「编辑」按钮（仅在 ready 态出现）。
- `editOpen` ref + `<EditWorkspace v-if="editOpen" :analysis="result" @close @saved>`；
  `saved` 时更新 `result`（含 engine/bpm/edited 同步）与 `history` 刷新。
- **BPM 徽标**：结果页第一行「和弦标记」旁，`result.bpm ? ♩=128 : 无`；
  `result.bpm == null` 时静默发起 `GET /api/analyses/{id}/beats` 回填（不阻塞页面）。
- **重新识别确认**：`result.edited` 时，历史行「重新识别」与结果页引擎切换
  先弹 `ConfirmDialog`（"重新识别将覆盖本次人工修改…"），确认后照常执行；
  未编辑过则直接执行。
- reanalyze 成功响应里 `edited:false` → 徽标消失。

### 4.4 HistoryList.vue / ChordTimeline.vue

- HistoryList：记录 `edited` 为真时，文件名旁/引擎徽标侧显示「已编辑」细金字徽标。
- ChordTimeline：`onMounted` 注册 `events.on('player:pause', pause)`；`onUnmounted` 注销。

## 5. 边界与约束

| 场景 | 行为 |
| --- | --- |
| 非法和弦名 | 红框 + 行级错误；存在非法行时保存禁用 |
| 时间夹取 | 每条 `start ∈ [prev.start, next.start]`（首条 ≥0，末条 ≤ duration） |
| 拖出区间 | 钳制，不越界 |
| 至少 1 条 | 删除守卫；空数组请求后端 422 |
| 播放中打开编辑器 | 自动暂停；编辑期间不发声（键盘预览不发声，仅点亮） |
| beats 检测失败/无网络 | 网格不显示，显示"未检测到节拍"；编辑其余功能正常；BPM 徽标隐藏 |
| 变速/散板歌曲 | 吸附可关；±0.1s 微调兜底；每小节拍数可调（1–12） |
| 旧记录（无 bpm/beats） | 打开编辑器/结果页时按需计算并入库 |
| 保存后 | 双档/键盘/试听/导出/历史立即一致；编辑不影响音频文件与缓存键 |

## 附录 A：v2 DAW 风格工作台（替代 §4.2 的迷你时间轴 + 列表）

界面：
- 工具栏：`适配 | − | 缩放滑块 | ＋ | px/s` ＋ 网格密度（小节/拍/8分/16分）＋ 每小节拍数 ＋ 吸附开关
- **编曲视图**（主区，水平滚动）：刻度尺（上排小节号、下排秒刻度）+ 音轨泳道；
  和弦渲染为**连续色块**（N 虚线弱化），选中块金色高亮并显示左右边缘手柄
- **检查器**（底部）：选中块的和弦名输入（实时校验）、起点 `−/+0.1s`、时长、分割/删除
- 底部键盘预览沿用（选中有效和弦时显示构成音）

交互映射（DAW 习惯）：
| 操作 | 行为 |
| --- | --- |
| 拖块左/右边缘 | 调整该边界时间（吸附网格，夹取相邻边界） |
| 拖块中部 | 整体平移该段（末块=移动起点，末端固定音频结束） |
| 双击块内 | 在光标处**分割**（新增标记，继承原名） |
| Delete / 退格 | 删除选中块（头部段并入后段，其余并入前段） |
| ⌘/Ctrl + 滚轮 | 以光标为锚缩放；普通滚轮横向平移 |
| 适配按钮 | 整曲铺满视口宽度 |
| 缩放滑块 / ± | 2–900 px/s 连续缩放 |

缩放与网格渲染：
- 网格线**自动抽稀**：屏上相邻线距 ≥9px；密度档位决定细分上限（16分最细），
  优先保留粗刻度（小节 > 拍 > 8分 > 16分）
- 秒刻度按 0.5/1/2/5/10/15/30/60s 自适应（≥70px/格）；小节号按可用宽度跳号
- 吸附网格按密度档位构造（`小节`档仅小节线）
